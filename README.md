# DualScreen Launcher

DualScreen Launcher is an Android game launcher built for dual-screen handhelds such as the AYN Thor. It brings supported PC and Nintendo Switch games into one interface and applies game-specific configurations and custom dual-screen mods so gameplay can use both displays.

You must provide your own legally obtained game files. Games and copyrighted game data are not included.

## Game library

The launcher currently lists **13 PC games and 7 Nintendo Switch games**. Integration varies by title. Beta and development entries are works in progress; a listed game does not mean every companion feature is complete. Check the in-app game details for the required build before installing your files.

## Get access

Access is available to active Patreon supporters or people who receive an access code directly from the developer.

1. [Join the Patreon](https://www.patreon.com/c/ProfMags).
2. [Download the latest APK](https://github.com/JoeCorrell/DualScreen-Launcher/releases/latest).
3. Install and open the app, then choose **Sign in with Patreon**.
4. Sign in with the Patreon account that has the active membership. If you were given an access code, enter it on the same screen instead.

Patreon memberships are securely rechecked periodically and must remain active. If you need help, join the [Discord server](https://discord.gg/j4tTYMHYRn).

This public repository contains downloads and release information only. The source code is maintained privately.
